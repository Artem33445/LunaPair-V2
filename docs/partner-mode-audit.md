# Аудит партнёрского режима LunaPair

## Текущее состояние

- Роль `partner` уже есть в профиле и маршрутизации.
- Текущий экран партнёра находится в `src/features/partner/pages/PartnerPage.tsx`.
- Настройки доступа партнёра находятся в профиле, но представлены как простой список чекбоксов.
- Текущая модель `PartnerSharingPreferences` слишком узкая: часть категорий отсутствует, нет паузы доступа, отключения партнёра, уровней доступа и отдельных разрешений для календаря, статистики, сна, энергии, комментариев и предпочтений поддержки.
- Текущий `filterPartnerLog()` возвращает `Partial<DailyLog>`, поэтому партнёрский UI всё ещё работает рядом с исходной моделью дневника.
- Фильтрация есть, но она недостаточно строгая: энергия и сон проходили без явного разрешения.
- Partner preview работает локально через смену роли и демо-данные, но интерфейс показывает мало информации и не объясняет честно границы локального режима.

## Ограничения и риски приватности

- Нет принципа "запрещено по умолчанию" для всех чувствительных категорий.
- Нет безопасной read-only модели для партнёра.
- Нет отдельной проверки, что скрытые значения отсутствуют в данных, переданных партнёрскому UI.
- Нет возможности приостановить доступ или отключить партнёра.
- Нет возможности скрыть конкретный день или заметку.
- Нет готовых уровней доступа.
- Нет полноценного календаря партнёра с просмотром конкретного дня.
- Нет маршрутизационного guard: партнёр может вручную открыть tracker-only маршруты.
- Нет write guard: операции записи не проверяют роль перед изменением локальных данных.
- Настройки доступа партнёра не дают понятного preview того, что увидит партнёр.

## План исправлений

1. Расширить `PartnerSharingPreferences` и добавить локальную нормализацию старых данных.
2. Добавить safe-модели `PartnerVisibleDay`, `PartnerDashboardData`, `PartnerSupportCard`, `PartnerPermissionsSummary`.
3. Создать `buildPartnerDashboardData()` и не передавать в партнёрский UI исходные `DailyLog`, `CycleEntry`, `AppProfile`.
4. Добавить локальные сервисные интерфейсы и реализации для будущей замены на Firebase.
5. Пересобрать экран партнёра: сегодня, прогноз, календарь, день, история, статистика, рекомендации.
6. Обновить настройки профиля: уровни доступа, категории, preview, пауза, отключение партнёра.
7. Добавить в дневник настройки скрытия конкретного дня и заметки.
8. Защитить tracker-only маршруты и операции записи для роли `partner`.
9. Добавить тесты разрешений, скрытия данных и рекомендаций.
