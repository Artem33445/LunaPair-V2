# LunaPair: правила разработки

## Назначение проекта

LunaPair — русскоязычное frontend-only PWA-приложение для локального ведения календаря менструального цикла, ежедневного самочувствия и демонстрационного режима партнёра. Первая версия хранит данные только на устройстве.

## Стек

- React, TypeScript strict, Vite.
- React Router для маршрутизации.
- Tailwind CSS и shadcn/ui-подход к доступным базовым компонентам.
- Lucide React для иконок.
- Zustand для состояния интерфейса.
- Dexie и IndexedDB для пользовательских данных.
- localStorage только для темы, onboarding и небольших настроек.
- date-fns для дат, Recharts для графиков, Framer Motion для лёгких анимаций.
- vite-plugin-pwa для установки и офлайн-режима.
- Vitest, React Testing Library, ESLint, Prettier.

## Архитектурные правила

- UI-компоненты не обращаются к IndexedDB напрямую.
- Все обращения к данным идут через repository-слой и интерфейсы репозиториев.
- Логика расчётов цикла находится в чистых функциях отдельно от UI.
- Код должен быть готов к будущей замене локальных репозиториев на Firebase-реализации.
- Не добавлять backend, сервер, облачную базу, Firebase SDK, Supabase, аналитику, рекламу или внешние API на текущем этапе.
- Не хранить чувствительные записи в URL и не выводить пользовательские данные в console.log.
- Сохранять медицинские предупреждения во всех местах, где показываются прогнозы.
- Не копировать дизайн, тексты, структуру, логотипы или иллюстрации Flo.
- Весь пользовательский интерфейс остаётся русскоязычным.

## Именование

- Компоненты: `PascalCase.tsx`.
- Хуки: `useSomething.ts`.
- Чистые доменные функции: глагол или существительное в `camelCase`.
- Типы и интерфейсы: `PascalCase`.
- Репозитории: интерфейс `SomethingRepository`, локальная реализация `LocalSomethingRepository`.

## Команды

- `npm install` — установка зависимостей.
- `npm run dev` — локальный запуск.
- `npm run build` — production-сборка и проверка TypeScript.
- `npm run preview` — просмотр production-сборки.
- `npm run test` — автоматические тесты.
- `npm run lint` — проверка качества кода.
