# LunaPair

LunaPair — первая рабочая frontend-only версия приложения для ведения календаря менструального цикла, ежедневных записей самочувствия и демонстрационного режима партнёра. Интерфейс полностью русскоязычный, данные хранятся только локально на устройстве.

Приложение не является медицинским устройством, не ставит диагнозы и не заменяет консультацию специалиста. Расчёт фертильного окна и даты следующих месячных приблизительный.

## Возможности

- Выбор роли: девушка или партнёр.
- Onboarding для девушки с датой последних месячных, длиной цикла, длительностью месячных и темой.
- Отдельный onboarding партнёра с честным демо-режимом без фальшивой синхронизации.
- Главный экран с днём цикла, фазой, ближайшими датами и безопасным предупреждением.
- Календарь с фактическими и прогнозируемыми днями.
- Календарь с фазами цикла: месячные, фолликулярная фаза, фертильное окно, овуляция и лютеиновая фаза.
- Быстрое окно записи при нажатии на дату в календаре.
- Добавление, обновление и очистка ежедневных записей.
- Компактное отслеживание настроения, самочувствия, симптомов, боли, сна, энергии, интимной близости и описания дня.
- История прошлых циклов с локальными отчётами.
- Локальный ассистент по вопросам календаря и данных приложения без внешних API.
- Отметка начала и окончания месячных.
- Статистика по локальным данным.
- Настройки темы, роли и разрешений партнёра.
- Экспорт и импорт JSON-резервной копии.
- Очистка всех локальных данных.
- PWA manifest, service worker и офлайн-доступ к основным экранам после первой загрузки.

## Технологии

React, TypeScript strict, Vite, React Router, Tailwind CSS, shadcn/ui-подход на Radix UI, Lucide React, Zustand, Dexie, IndexedDB, date-fns, Recharts, Framer Motion, vite-plugin-pwa, Vitest, React Testing Library, ESLint и Prettier.

## Структура

- `src/app` — точка приложения, стили и роутинг.
- `src/components` — базовые UI-компоненты, layout и состояния.
- `src/features/onboarding` — splash, выбор роли и onboarding.
- `src/features/cycle` — экраны цикла, календарь и чистые расчёты.
- `src/features/daily-log` — ежедневные записи.
- `src/features/assistant` — локальный ассистент без API-ключей.
- `src/features/insights` — статистика.
- `src/features/partner` — demo и preview с фильтрацией данных.
- `src/features/profile` — настройки, приватность, импорт и экспорт.
- `src/db` — Dexie и локальные репозитории.
- `src/services` — экспорт, импорт и NoopSyncService.
- `scripts/local-preview.cjs` — простой локальный сервер для собранной версии.
- `src/i18n/ru.ts` — основные русские тексты.
- `public/icons` — оригинальный SVG-логотип и PWA-иконки.

## Установка и запуск

```bash
npm install
npm run dev
```

Production-сборка:

```bash
npm run build
npm run preview
```

Для просмотра уже собранной версии без Vite preview можно использовать:

```bash
npm run local-preview
```

Проверки:

```bash
npm run test
npm run lint
```

## Локальное хранение

Профиль, циклы и ежедневные записи сохраняются в IndexedDB через Dexie. `localStorage` используется только для темы и небольших onboarding-настроек. Приложение не отправляет записи в интернет, не использует внешние API, рекламу или стороннюю аналитику.

## Ограничения первой версии

- Нет аккаунтов и авторизации.
- Нет реальной синхронизации пары.
- Нет Firebase, Supabase или собственного сервера.
- Партнёрский режим использует demo-данные или локальный preview разрешённых категорий.
- Прогнозы основаны на введённых данных и не гарантируют медицинскую точность.

## План подключения Firebase

1. Добавить Firebase SDK только на следующем этапе.
2. Реализовать `AuthService` с анонимным входом или email/Google-входом после отдельного UX-решения.
3. Создать Firebase-версии `CycleRepository`, `DailyLogRepository`, `ProfileRepository` и `PartnerConnectionRepository`.
4. Добавить защищённые коды пары и правила Firestore Security Rules.
5. Реализовать `SyncService` с явным статусом синхронизации и конфликтами.
6. Добавить экран управления подключением партнёра, отзывом доступа и журналом устройств.
7. Расширить тесты на миграцию из локального режима в облачный.
